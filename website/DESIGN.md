# Screenline 官网设计上下文

## 目标与边界

这是 `https://screenline.xiaogao.xyz/` 的中文产品发布网站，服务希望更方便地使用临时截图的 Windows 用户。单一主要任务是：看懂晾台交互，下载 Windows 程序。网站是营销与内容页面，不是应用仪表盘，不继承原生工具中禁止营销页的布局约束，也不修改仓库根目录的 WPF 设计约定。产品事实与中文内容见同目录 `content-plan.md`；当前程序行为以仓库 README 为准。

网站的独特之处来自产品本身：**微弯绳索上，木夹挂着白色截图相框**。首屏在这一处表达真实的物理隐喻，其他内容安静、易读，避免泛化的科技渐变、炫光、装饰数字、虚构用户评价与指标。

## 视觉方向与取舍

采用冷浅蓝的桌面晨光感，用深蓝文字与白相框建立清楚层次。首屏是文字与横跨场景的晾衣绳，真实截图为主角；不把产品塞进无关的电脑外壳，不以密集功能卡片取代实际外观。

考虑过通用软件双栏首屏与多块功能卡片，但它会削弱“截图晾台”的识别。最终以一条绳索和错落相框作为唯一视觉 signature，后续使用横线、文字和操作图说明行为。正文区不反复复制相框装饰。

## 颜色与 CSS 映射

本文件拥有网站的视觉意图与规范值，网站全局样式中的 `:root` 自定义属性是运行时唯一取值入口；组件通过这些变量消费，不另建独立配色。下表沿用原生应用品牌，并仅为网页木夹加入必要的实物色。

| 角色 | CSS 变量建议 | 值 | 用途 |
| --- | --- | --- | --- |
| 纸面 / 浅蓝 | `--surface` | `#EDF4F7` | 页面主背景、静态演示背景 |
| 深蓝 | `--primary` | `#24465D` | 主按钮、重点链接、键盘焦点 |
| 正文 | `--foreground` | `#1F3340` | 主标题与正文 |
| 次级文字 | `--muted` | `#59717F` | 辅助说明、元信息；不可再随意减低透明度 |
| 分隔线 | `--border` | `#D7E3E9` | 分区、次级按钮边线 |
| 相框 | `--white` | `#FFFFFF` | 相框、按钮文字、必要内容面 |
| 绳索 | `--rope` | `#8094A0` | 弯绳与结构细节，不承担小字信息 |
| 木夹 | `--wood` | `#B89B6E` | 木夹与首屏小圆点，不充当正文文字色 |

按钮 hover、active、边框、焦点、阴影和滚动条均从上述变量或由其计算的透明色派生。错误和提示必须有文字，不能仅靠颜色区别。实际对比度在实现时检查；普通正文目标至少 4.5:1，大字与可识别界面边界至少 3:1。

## 字体与字级

不请求第三方字体，优先 Windows 本机字库，减少国内访问依赖与字体替换位移。

| 角色 | 字体栈与建议 | 使用方式 |
| --- | --- | --- |
| 中文主标题 | `"Microsoft YaHei UI", "Microsoft YaHei", "Segoe UI", system-ui, sans-serif`，650 | 桌面约 56–62 px、窄屏 30–44 px；行高 1.3–1.45，轻微字距收紧最多 0.045 em |
| 正文与导航 | `"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", system-ui, sans-serif`，400/600 | 正文 14–17 px、行高约 1.75–1.95；辅助元信息最低 12 px |
| 英文品牌 | `"Segoe UI", sans-serif`，500/600 | 顶部标志组成部分为 8–9 px 大写英文小标；其他正文英文不得据此缩小 |
| 快捷键与版本 | `"Cascadia Code", Consolas, "Microsoft YaHei UI", monospace`，400/600 | 快捷键保留不换行单元，版本短信息保持等宽易比较；紧凑键帽允许 8–10 px，但操作中文说明保留 12 px 以上 |

主标题允许有意换行，但不得因不同版本号或异步查询结果改变结构。字体大小和行高用全局角色变量，不在相同角色间零散修改。

## 布局与密度

页面使用浏览器文档滚动，正文最大宽度约 1120–1200 px；桌面两侧留足 32–56 px，窄屏 20–24 px。首屏的文字区保持清楚阅读宽度，演示舞台可越过正文边界，但不得造成页面横向滚动。

建议顺序：

```text
品牌 / 怎么用 / 下载 / 常见问题 / GitHub

Windows 10 / 11 · x64
把截图挂在屏幕上沿，随手取用。
一句说明 + 安装包 / 便携版 + 备用下载
──────── 微弯绳索 / 木夹 / 真实截图白相框 ────────

截图与展开 → 复制与拖出 → 预览与标注
下载与系统要求 / 校验入口
常见问题
图片留在本机 / 网站访问说明 / 开源来源
```

顶部导航可保持普通流；若实现粘性导航，锚点使用 `scroll-margin-top`，不能遮挡标题和键盘焦点。不要使用整页 `height: 100vh`、页面 `overflow: hidden` 或连续整屏滚动劫持。

分区纵向间距桌面约 80–112 px，窄屏约 48–64 px。功能以图文或横向操作条组织，无意义的多层卡片、标签堆叠和装饰编号应删除。只有真实操作序列才使用顺序标记。

## 相框与素材

相框采用纯白面、轻微圆角（约 8 px）、有限的柔和阴影；夹子窄而朴素。相框之间可有约 −3° 到 3° 的静态倾斜，截图区域尺寸预留稳定，文字说明保持水平。首屏相框不承载必须依赖旋转文字阅读的信息。

先使用仓库自己的产品截图，或合成的无隐私示例图片；不复用 Tendedero 的图标、名称资产或文档截图。为图片写准确替代文本；同一内容已被旁边说明完整表达时，装饰木夹、绳索与重复缩略图使用空替代文本或 `aria-hidden`。所有图片保留明确宽高或比例，避免加载后跳动。

## 响应式

- 宽屏（约 1024 px 及以上）：文本与演示相互呼应，晾衣绳横向延伸；主要下载按钮并排。
- 中屏：相框数量减少，保持主截图的可辨识度；不靠缩小正文塞下桌面构图。
- 窄屏（320–767 px）：首屏文字在上，主要演示在下；一张主截图与部分次图足够。操作说明纵向排布，按钮可全宽，导航精简成真实链接。保留 Windows 系统要求，不把移动设备误称为受支持平台。
- 200% 缩放下自然回流；快捷键单元、长文件名、下载说明、URL 和中文连续文本均不会撑破容器。下载链接在移动设备上仍可访问，不仅依据 UA 隐藏。

## 动效

首屏最多一次 300–500 ms 的轻微淡入和相框归位；不要无限摇晃、自动滑动、滚动跟随旋转或大范围视差。按钮与链接反馈约 120–180 ms，不改变布局尺寸。可交互演示若存在，只增强产品理解，点击与键盘都可操作，并标明它是网页演示。

`prefers-reduced-motion: reduce` 下取消出场位移、旋转过渡与平滑滚动，所有内容立即可见。内容不得依赖 JavaScript 动画完成才出现。

## 交互与可访问性

目标为 WCAG 2.2 AA。使用中文 `lang="zh-CN"`，语义化 `header`、`nav`、`main`、`section`、`footer`，仅一个 `h1`，标题层级连贯。下载与站外跳转用真实 `<a>`；展开常见问题可用原生 `details/summary`，不为纯内容页面引入复杂自制控件。

提供跳到主要内容的链接，所有交互支持 Tab 和清楚的 `:focus-visible`。焦点环建议 3 px 深蓝并留出 3 px 间隔，不裁切；高对比/forced-colors 模式依赖系统颜色保持可见。链接不能只靠颜色辨识，正文链接保留下划线或等效稳定提示。触控目标建议至少 44 × 44 px。

下载按钮必须包含“Windows 安装包”或“便携版”等实际动作名，不能只写“立即体验”。指向 exe、zip、SHA 校验文件的链接有可理解的名称；外链若新开页，应在可访问名称或旁边提示。无需强制新开页。

页面只需要版本下载信息的轻量异步状态：始终保留明确的 GitHub 备用入口；固定版本文字和按钮的空间；失败在原位说明，不弹浏览器原生 alert。数据未就绪时不要展示伪造的最新版。安装器的安全提示与隐私说明保持可见，不能只放在 hover 或工具提示里。

滚动条保持可见并可操作。全局基线用品牌派生的 thumb/track/hover/active，保留标准浏览器几何；forced-colors 使用系统默认，不通过隐藏滚动条维持美观。

## 发布前视觉核对

核对桌面与 360 px 窄屏、键盘浏览、200% 缩放、减少动效、图片失败和版本信息失败。首屏必须能同时说明产品、显示主要下载和真实外观；截图比例稳定；所有可点击内容有 hover 与焦点反馈；没有移动端横向滚动。版本/下载来源与实际签名清单一致，网站不会宣称未实现的产品能力。网站访问日志与应用本地数据分开说明。

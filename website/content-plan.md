## 日常操作文案

区块标题：**截图之后，下一步更顺手。**

按真实操作顺序组织，使用下面的短文案；不把互相独立的功能强行编号成流程：

| 操作 | 标题与正文 |
| --- | --- |
| 截图与导入 | **截图放上来。** 按 `Ctrl + Alt + S` 拖选区域，或把已有图片拖进晾台。也可以在设置中添加截图保存目录，收集监控开始后新增的图片。 |
| 展开与收起 | **需要时，抬手就到。** 按 `Ctrl + Alt + T`，或把鼠标停在屏幕顶边约 350 ms，展开晾台；晾台内按 `Esc` 收起。 |
| 复制与拖出 | **随手带进下一处。** 单击卡片复制图片与文件引用，或拖到支持图片、文件拖放的应用中；晾台保留自己的副本。 |
| 预览与标注 | **看清楚，再画两笔。** 双击图片预览原图，长按约 500 ms 进入画笔标注；保存标注会生成新副本。 |
| 移出与撤销 | **临时移出，还能找回。** 点击叉号移出卡片，按 `Ctrl + Z` 或从托盘撤销。移出不会删除本地图片文件。 |

首屏附近只强调两个主要快捷键，完整操作留给这个区块与使用说明。不要让访问者误以为在网页按快捷键就能运行 Windows 程序。

## 常见问题定稿

**能与 Windows 自带截图一起使用吗？**

可以。Screenline 有自己的区域截图入口，也可以监控指定截图目录。只复制到剪贴板的截图，可从托盘主动粘贴，或在设置中开启“收集剪贴板中的纯图片”；后台剪贴板收集默认关闭。

**启动后为什么看不到主窗口？**

程序常驻系统托盘，首次展开后会自动收起。按 `Ctrl + Alt + T`，或查看任务栏的隐藏图标区。

**可以自动更新吗？**

可以手动检查更新，也可在设置中开启“启动时检查更新”；启动检查默认关闭。更新优先读取国内签名清单，失败时回退 GitHub。有新版时提醒，由你确认下载和运行安装器，不会静默安装。国内安装包下载失败可重试或使用 GitHub 备用下载，不会自动换成另一来源的安装包。

**为什么首次运行有 Windows 安全提示？**

当前程序和安装器尚未代码签名，Windows 可能显示 SmartScreen 提示。请从官网列出的项目来源下载，并核对同一版本的 SHA-256。更新清单签名与文件校验不等于 Windows 代码签名。

**移出卡片会删除原图吗？卸载后呢？**

不会。导入时会建立自己的本地副本，移出只更改晾台列表。升级和卸载也保留 `%LOCALAPPDATA%\Screenline` 中的图片与设置；需要清理时，先退出程序并备份该目录。

**是否支持 ARM 或所有多显示器场景？**

当前下载面向 Windows x64。ARM64、混合 DPI、多显示器热插拔与游戏独占全屏尚未完成实机验证。更多限制见 Windows 使用说明。

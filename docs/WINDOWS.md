# Windows 使用说明

适用于 Screenline / 截图晾台当前版本，Windows 10 / 11 x64。

## 安装与首次运行

从仓库的 [最新 Release](https://github.com/xiaogao007/screenline-windows/releases/latest) 下载 Windows x64 ZIP，完整解压后双击 `Screenline.exe`。不要直接在压缩包内运行。请保留同目录中的 `Screenline.exe.config`；程序使用 .NET Framework 4.8。

应用常驻系统托盘，不会一直在任务栏显示主窗口。托盘图标可能被 Windows 收进“显示隐藏的图标”区域。右键图标可截图、导入图片、粘贴剪贴板图片、打开设置、本地图库或退出。

首次运行可能出现 Windows SmartScreen 提示：当前程序尚未代码签名。请先核对下载来源及 Release 附带的 SHA-256 校验值，依据系统提示和自己的安全判断决定是否运行；也可以自行审查并构建源码。项目不提供证书或已签名安装包。

## 校验下载文件

在 PowerShell 中计算下载 ZIP 的 SHA-256，并与同一 Release 公布的校验值逐字比对：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\Screenline-vX.Y.Z-windows-x64.zip
```

将 `vX.Y.Z` 替换为实际版本号，并与同一 Release 中 `SHA256SUMS.txt` 对应文件的值比较。校验值不同或来源不明时，请重新从仓库的 Release 下载。

从 v0.1.2 起，标签发布由 GitHub Actions 在 Windows runner 上构建，并通过项目自检后生成下载附件。可以在 [Actions](https://github.com/xiaogao007/screenline-windows/actions) 查看对应标签的执行记录；自检覆盖范围见 [README](../README.md#从源码构建)。自检无法代替所有显示器配置和桌面交互的实机验证。

## 日常使用

- **展开晾台：** 按 `Ctrl + Alt + T`，或把鼠标停在显示器顶边约 350 ms。
- **区域截图：** 按 `Ctrl + Alt + S` 后拖选范围，`Esc` 取消。截图成功后会加入本地图库。
- **导入已有图片：** 展开晾台，点击“导入”，或把图片文件拖入晾台。
- **复制与拖出：** 单击卡片复制图片与文件引用；拖到支持图片或文件拖放的应用中使用。晾台保留自己的副本。
- **预览与标注：** 双击查看原图，长按约 500 ms 进入画笔标注；保存标注会生成新副本。
- **移出与恢复：** 点击卡片叉号移出；按 `Ctrl + Z` 或使用托盘“撤销移出”恢复。移出不会删除图片文件。

完整操作表见 [README](../README.md#快捷键与操作)。

## 自动收集截图

默认监控图片目录的 `Screenshots` 子文件夹及可用的 OneDrive 截图目录。它只收集启动监控后新增的图片，不会自动导入文件夹中已有的图片。

如果系统截图保存到了其他位置，在托盘“设置”中添加实际目录。应用不会更改 Windows 截图工具、`Win + Shift + S` 或 `Win + PrtSc` 的系统保存设置。

“收集剪贴板中的纯图片”默认关闭。需要收集 `Win + Shift + S` 等工具复制的新截图时，可在设置中手动开启。应用跳过含文字、文件或支持的隐私标记的混合内容。不启用监控时，也可以通过托盘“粘贴剪贴板图片”主动导入。

## 常见问题

### 双击后看不到窗口

先查看系统托盘或隐藏图标区，再按 `Ctrl + Alt + T`。应用首次展示后会自动收起；再次启动同一个程序不会创建第二个实例。

### 快捷键没有反应

其他应用可能已占用组合键。Screenline 会显示相关提示，此时使用托盘菜单操作。当前版本暂不支持自定义快捷键。

### 全屏时鼠标移到顶边没有展开

默认启用“应用全屏时暂停自动展开”。可以使用快捷键或托盘主动展开，或到设置中关闭该选项。游戏独占全屏尚未完成实机验证。

### 截图没有自动加入

确认“自动收集截图文件夹中的新图片”已开启，并检查监控目录是否等于截图工具实际保存的位置。只有监控开始后新增的 PNG、JPG/JPEG、BMP、GIF 会被导入。仅复制到剪贴板的截图，需要主动粘贴或手动开启剪贴板图片监控。

### 拖到某个应用没有反应

目标应用需要支持接收图片或文件拖放。可尝试单击卡片复制后粘贴，或使用卡片“另存图片”保存副本。

### 移出图片后磁盘空间没有减少

这是当前版本的行为：移出只改变晾台列表并保留撤销记录，图片副本仍在本地图库，不会进入 Windows 回收站。若需要清理，先从托盘退出程序，再备份或整理 `%LOCALAPPDATA%\Screenline`。自行删除的图片将无法通过撤销恢复。

### 如何升级、备份或卸载

升级前从托盘退出程序，备份 `%LOCALAPPDATA%\Screenline`，然后将新 Release 完整解压到固定位置。应用没有自动更新。

备份 `%LOCALAPPDATA%\Screenline` 可保留图片、设置及索引。移动程序后，如之前开启了“登录 Windows 后启动”，请在新位置运行后取消该选项并保存，再重新勾选并保存。

卸载时先在设置中关闭“登录 Windows 后启动”并保存，再从托盘退出，删除解压的程序文件夹即可。本地数据会继续保留；确认已备份后，可自行删除 `%LOCALAPPDATA%\Screenline`。

## 反馈问题

提交 Issue 时建议提供 Windows 版本、Screenline 版本、显示器数量及缩放比例，以及能够重复问题的操作步骤。错误日志为 `%LOCALAPPDATA%\Screenline\errors.log`（仅在发生并记录异常后生成）。上传日志或截图前请检查其中的路径、图片内容与其他个人信息。

混合 DPI、多显示器热插拔、游戏独占全屏、屏幕阅读器及 ARM64 尚未完成实机验证。未实现的功能与平台差异见 [迁移说明](MIGRATION.md)。
